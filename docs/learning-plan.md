# Smart Parking Lot Learning Plan

This plan will grow one runnable parking system through 12 milestones. Each milestone adds a useful behavior and the Java or design concept needed to support it. We implement only the current milestone; later milestones remain a roadmap until the learner is ready.

## Milestones

1. Java setup and a packaged application.
2. Domain enums and value objects.
3. Encapsulation, valid parking-spot state, and selectable allocation policies.
4. Generic repository and in-memory persistence.
5. Check-in orchestration using the selected allocation strategy.
6. Check-in invariants and failure consistency.
7. Check-out workflow, duration, and immutable receipts.
8. Strategy and Factory patterns for fees.
9. Real-time availability and console interaction.
10. Concurrency and atomic parking transactions.
11. Relational database schema and transaction boundaries.
12. Tests, extensions, and production evolution.

## Format Used By Every Guide

Each guide explains what and why, Java concepts, SOLID or patterns, failure modes, tradeoffs, the smallest implementation, verification, and a learner exercise.

## Recommended Order

Read the current guide, inspect the small code change, compile, and run the verification. Complete the exercise or discuss the reflection before moving forward. At that point, create the next guide and implementation together.
