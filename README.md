# Smart Parking Lot

A step-by-step Java learning project for designing a multi-floor parking lot backend.

## Current Progress

We completed Milestones 1-8 and are now at **Milestone 9: live availability and console interaction**.

Future milestone code is intentionally absent. We will design and implement it together, one small working change at a time.

## Run

Requires JDK 17 or newer.

```bash
mkdir -p out
javac -d out $(find src -name '*.java')
java -cp out com.airtribe.smartparkinglot.Main
```

Start with [the learning plan](docs/learning-plan.md), then work through the currently available milestone guide. The next guide will be added only when we reach that milestone.
